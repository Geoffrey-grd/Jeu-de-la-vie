## 📖 Pour les développeurs
Le code source est disponible dans le repo pour ceux qui veuelent voir comment tout fonctionne mais attention à bien suivre les étapes : 

## Prerequis
SFML
Visual studio

## Etape 1 : Installation de SFML
👉 [Téléchargez la version 2.6.2 de 2022 en *64 de sfml ici]((https://www.sfml-dev.org/download/sfml/2.6.2/))

Puis dezippez le dossier dans votre disque directement pour faciliter l'accès 
  exemple de chemin d'accès pour un disque C : C:\


## Etape 2 : Clonage du repo
Dans un nouveau projet en application console, clonez le repo


## Etape 3 : parametrage de la solution
Dans le dossier de votre nouveau projet, rendez vous dans sfml/bin et copier/coller tous .dll dans *64/debug
Revenez ensuite dans le dossier projet et éxecutez le ficher "Jeu-de-la-vie.sln" qui configurera vles paramètre de visual studio.


## Etape 4 : Amusez vous!
